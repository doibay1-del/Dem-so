HƯỚNG DẪN — ĐẾM SỐ & TÍNH TIỀN PWA

1. Giải nén ZIP.
2. Tải TẤT CẢ file trong thư mục này lên thư mục gốc của repository GitHub công khai. Giữ nguyên tên và không bỏ sót index.html, manifest.webmanifest, sw.js, icon-192.png, icon-512.png.
3. GitHub → repository → Settings → Pages → Build and deployment:
   - Source: Deploy from a branch
   - Branch: main
   - Folder: /(root)
   - Save
4. Chờ xuất bản và mở URL HTTPS GitHub Pages.

CÀI IPHONE:
- Mở URL bằng Safari → Chia sẻ → Thêm vào MH chính (Add to Home Screen) → Add.
- Nếu xuất hiện “Open as Web App”, bật tùy chọn đó.

CÀI ANDROID:
- Mở URL bằng Chrome → menu ⋮ → Install app hoặc Add to Home screen → xác nhận.

KIỂM TRA:
Nhập 10, 20, abc, 40; đơn giá 23000. Kết quả: 4 phần tử, 3 số hợp lệ, thành tiền 69.000 đ.

Lưu ý: website GitHub Pages công khai. Không tải dữ liệu riêng tư lên repository. Mở lần đầu cần có Internet; hỗ trợ ngoại tuyến cần service worker được đăng ký thành công qua HTTPS.
